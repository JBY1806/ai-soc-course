## 공통 — 파형을 열 때마다 (모든 ID 같음)

1. **Vivado 를 완전히 껐다 켠다** (한 번 연 Vivado 에는 옛 파형이 남을 수 있음). ID 를 바꿀 때도 껐다 켜는 게 안전.
2. 시작 화면 (프로젝트 안 열어도 됨) 아래 **Tcl Console** 에 그 ID 의 `source …` 한 줄을 붙여 넣고 Enter.
3. **그룹을 펼친다** : 이름 왼쪽에 ▶ 가 있는 줄 (그룹) 의 ▶ 를 누른다. 사진마다 펼칠 · 닫을 그룹을 적어 둠. **버스 (값 칸이 `[7:0]` 같은 것) 는 펼치지 않는다.**
4. **파란 선택 표시는 신경 쓰지 않는다** : Vivado 파형 창은 늘 한 줄을 선택해 두어서 신호 이름 · Value 칸에 파란 테두리가 남는다 (빈 곳을 눌러도 안 풀림). 그대로 찍으면 된다 — 보고서에 넣을 때 처리.
5. 파형 창 위쪽 탭이 아니라 **파형 안 아무 데나 한 번 클릭** 해야 Ctrl + 휠 확대가 먹는다 — 클릭하면 노란 커서가 움직이니, 커서는 맨 마지막에 맞춘다.
6. `restart` 는 쓰지 않는다 (이 노트북에서 튕김). 파형을 다시 보고 싶으면 Vivado 를 껐다 켜고 `source` 를 다시.

## 공통 — 사진 한 장 찍는 순서

1. **확대** : 사진마다 적힌 구간 (시각) 이 화면에 차게. Ctrl + 마우스 휠 한 칸 = 두 배, 전체는 툴바의 Zoom Fit. 딱 안 맞으면 **조금 넓게** (양 끝은 잘라 맞춤). 보여야 하는 것의 시작 · 끝이 둘 다 화면 안에 들어왔는지 확인.
2. **커서 (노란 세로선, 1 개뿐)** : 파형 안에서 지정한 마커 선 위를 클릭해 노란 커서를 그 마커에 둔다. 왼쪽 Value 칸은 **노란 커서 시각의 값**이다. 마커 (위쪽 파란 이름표 · 파란 세로선) 는 스크립트가 미리 여러 개 꽂아 둔 표시라 따로 옮길 필요 없이 화면에 다 보인다.
3. **확인** : 아래 "보여야 하는 것" 이 화면에 다 보이는지 (값 글자가 읽히는지 — 안 읽히면 한 칸 더 확대).
4. **하지 말 것** : 신호 이름 클릭 (하늘색 선택), 노란 눈금 (Floating Ruler) 켠 채 찍기.
5. **캡처** : Win + Shift + S → **신호 이름 칸부터 파형 오른쪽 끝까지, 위쪽 시간 눈금 · 마커 이름표 포함**.
6. **보내기** : 채팅에 붙여 넣으면 확인하고 `Lec_verilog\UART_sender\캡처\` 에 저장. 보고서 그림 (번호 배지 · 화살표 · 번호별 설명 · 값 크게 · 색 범례 · 결과 상자) 은 그 다음에 만든다.

**색 뜻 (모든 파형 같음, 빨강 · 파랑 안 씀)** : 노랑 = 바깥 입력 (send_go · sel · data · tx) · 청록 = TX FIFO full · 분홍 = 상태 (c_state) · busy · uart_tx · 주황 = 잡아 둔 레지스터 (c_sel · c_data · c_idx) · TX FIFO 포인터 · 초록 = TX FIFO 로 넣는 글자 (push · push_data) · 흰색 = clk · rst · TB 계수 (cnt · busy_cnt · err)

**글자 보기** : 글자 줄 (`o_char` · `o_tx_push_data` · `pop_data` · `data_reg` · `rdata`) 은 **ASCII** 로 한 줄, 같은 신호를 **16 진** 으로 한 줄 더 넣은 곳이 있다. CR · LF 는 화면에 안 보이는 글자라 ASCII 줄에선 빈칸 · 이상한 글자로 나오고, 16 진 줄에서 **0d · 0a** 로 읽힌다.
