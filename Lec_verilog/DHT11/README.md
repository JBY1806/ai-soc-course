# DHT11 온습도 컨트롤러 — 보드 확인 (2026-10-30)

틱 카운트 방식 (1 µs tick 마다 FF 2 개 싱크로나이저를 거친 선 값을 보는 FSM, 상태 IDLE · START · WAIT · SYNC_L · SYNC_H · DATA_SYNC · BIT · STOP). btnR 한 번에 한 번 측정, 체크섬이 맞을 때만 값 갱신.

## 결과

| 순서 | 한 일 | FND (습도 · 온도) | 해석 |
|---|---|---|---|
| 1 | 처음 측정 | **3223** → 32 %RH · 23 ℃ | 0000 → 갱신 = 40 비트 · 체크섬 정상 |
| 2 | 센서에 입김 2 ~ 3 번 → btnR | **6224** → 62 %RH · 24 ℃ | 습도 +30 %RH |
| 3 | 수십 초 뒤 btnR | **3224** → 32 %RH · 24 ℃ | 습도 원래 값으로 회복 |
| 4 | 손가락으로 20 ~ 30 초 감싼 뒤 btnR | **6128** → 61 %RH · 28 ℃ | 온도 +4 ~ 5 ℃ (손 습기로 습도도 오름) |

- 센서 값의 변화에 맞게 FND 가 바뀜 → 시작 신호 · 응답 · 40 비트 수신 · 체크섬 · 표시 경로가 보드에서 동작.
- 비교용 기준기 (온습도계) 는 쓰지 않음 → 센서 정확도가 아니라 회로 동작 확인. 데이터시트 정확도 ±5 %RH · ±2 ℃.

## 조건

| 항목 | 값 |
|---|---|
| 보드 | Basys-3 (xc7a35t), 100 MHz |
| 배선 | DHT11 VCC → Pmod JA 6 번 (3.3 V), GND → 5 번, DATA → JA1 (J1, XDC PULLUP true) |
| 설계 상수 | START 19,000 µs · TIMEOUT 100 µs · 0 / 1 경계 40 µs · STOP 50 µs |
| 표시 | FND = 습도 정수 × 100 + 온도 정수, LED[15:8] 습도 · LED[7:0] 온도 (2 진) |
| 측정 간격 | 1 ~ 2 초 이상 (데이터시트) |
