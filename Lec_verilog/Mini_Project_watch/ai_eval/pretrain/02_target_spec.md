# 사전학습 2 — 타겟 환경과 시계 사양 (팀 BEST_Stop_watch_project, 2026-10-16 기준)

> 초안: 팀 저장소 boyun/merged_v4 와 10/16 팀 합의에서 옮김. 정보윤이 사양과 맞는지 확인할 것.

## 보드
- Digilent Basys-3, FPGA xc7a35tcpg236-1, 클럭 100 MHz (W5), 버튼 5개(C = 리셋), 스위치 16개, LED 16개, FND 4자리(공통 애노드, active low).
- 도구: Vivado 2022.2 (xsim), Icarus Verilog 12.0.

## 스위치 · 버튼 (Top `stopwatch_watch`)
| 입력 | 역할 |
|---|---|
| sw0 (sw_mode) | 0 시계, 1 스톱워치 |
| sw1 (sw_display_mode) | 0 초.1/100초, 1 시.분 |
| sw2 (sw_set) | 시계 1 = 시간 설정, 0 = 일반 |
| sw3 (sw_24h) | 0 = 12시간 표시(기본), 1 = 24시간 |
| sw4 (sw_timer) | 1 = 타이머 화면 (sw0 보다 우선) |
| btnC | 리셋 |
| btnR / btnL / btnU / btnD | 화면에 따라 다름 (아래) |

## 시계 (정보윤 담당: watch_control_unit · watch_datapath)
- 리셋 값 12:00:00.00, 내부는 24시간(0~23)으로 센다. 100 Hz tick 으로 항상 흐른다.
- sw2 = 1 → 설정 모드. 항상 **분 일의 자리**(FND 맨 오른쪽, cursor 0)부터 시작.
- 상태: NORMAL · SET_HOUR · SET_MIN_10 · SET_MIN_1. cursor = FND 자리 번호: 0 분 일, 1 분 십, 2 시 일, 3 없음(NORMAL).
- L = 왼쪽 자리로 (SET_MIN_1 → SET_MIN_10 → SET_HOUR → SET_MIN_1), R = 오른쪽 자리로 (반대 방향), 양 끝에서 돌아감.
- U = +1, D = −1. 분 십의 자리는 ±10. 그 칸만 돌고 다음 칸으로 올림 · 내림 없음 (분 59 +1 → 0, 시 그대로).
- 초 · 1/100초는 설정하지 않는다(팀 합의 10/16).
- 동시 입력 규칙: U 와 D 같은 클럭 → U. sw2 를 내리는 클럭의 버튼 → 무시(NORMAL 로). L 과 R 같은 클럭 → L.
- tick(자리 넘김)과 설정 버튼이 같은 클럭에 같은 카운터로 오면 → tick 만 반영(시각이 틀어지지 않게).
- 설정 중 sw1 = 1(시.분 화면)이면 cursor 자리가 1/100초 50~99 동안 꺼진다(점멸, FND 담당 정안성).
- 12/24 표시: sw3 = 0 이면 0시 → 12, 13~23시 → 1~11, 오후(12~23시)면 LED15 켜짐.

## 스톱워치 (이종혁 담당) · 타이머 — 참고
- 스톱워치: R 시작/정지, L 지우기(STOP 에서만), U 방향(STOP 에서만), D 랩(화면 고정, LED7).
- 타이머(sw4): U +10초, R +1분, D +10분, 최대 59:59, L 시작/취소, 0 이 되면 LED 16개 0.5초 점멸.

## 공통 구조
- 100 Hz tick_gen 하나를 셋이 같이 씀(시작 위상 오차 ≤ 10 ms). 4 kHz tick 하나로 디바운서 4개(8칸 = 2 ms) · FND 스캔.
