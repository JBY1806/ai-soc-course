과제 ③ "대시보드 UI" 용. `ai_eval\scores\` 의 세션 JSON 을 읽어 화면 한 장으로 보여 준다.

## 만들기 (세션이 늘 때마다)
```
cd C:\Users\LG\Developer\Lec_verilog\Mini_Project_watch\ai_eval\dashboard
py -3 make_dashboard.py
```
→ `dashboard.html` 이 새로 생긴다. 더블클릭으로 열린다(인터넷 필요 없음).

## 화면 구성 (교수님 자료 8·9쪽 예시와 같은 순서)
- 왼쪽 막대 / 위 탭: 설계(Design) 평가 ↔ 성능(Verification) 검증
- Assigned Role: `make_dashboard.py` 맨 위 `PROFILE` 을 고치면 바뀐다
- AI Score: 그 종류 세션 점수의 평균(교수님 예시 "AI 자동화 검증 평균")
- Session History: 1~3차 칸. 누르면 그 세션의 기준 막대·감점·확인 필요가 바뀐다. 없는 칸은 "대기"
- Criteria Details: 기준별 점수 막대 + `rubric.md` 의 "근거" 칸 글
- 검증 탭에만: 엣지 케이스 표(PASS/FAIL), TOTAL MISMATCH
- 위 노란 띠: 라벨에 "시험"이 들어간 세션이 있으면 자동으로 뜬다

## 캡처
- 주소 끝에 `#verif` 를 붙이면 검증 탭으로 열린다(`dashboard.html#verif`).
- 왼쪽 막대 맨 아래 달 모양 버튼 = 밝게/어둡게 전환. 보고서용은 밝게.

## 파일
- `make_dashboard.py` — 생성기 · `template.html` — 화면 틀 · `dashboard.html` — 결과(만들 때마다 덮어씀)
